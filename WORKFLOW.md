# GitHub workflow sandbox

This repository is a personal sandbox for testing issues, branches, and pull requests.

## Documentation workflow

1. Open an issue describing a small documentation improvement and its acceptance criteria.
2. Create a dedicated branch from the default branch.
3. Make the documentation change and check the diff for unrelated changes.
4. Open a pull request linking the issue with a closing keyword.
5. Check the changed files and any configured checks before merging.
6. Confirm that the pull request is merged and the linked issue is closed.

For a small documentation exercise, the repository owner can merge directly when repository rules allow it.
